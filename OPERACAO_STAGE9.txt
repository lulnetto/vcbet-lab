ETAPA 9 - OPERAÇÃO COMO SERVIÇO

Objetivo
- Subir um serviço HTTP local que dispara os fluxos atuais sem abandonar a CLI.
- Preparar a mesma base para uma UI web simples e futura UI mais completa.

Decisão arquitetural
- Manter os scripts atuais como workers de domínio.
- Criar uma camada de orquestração HTTP separada.
- Evitar duplicar regra de negócio agora.
- Tratar concorrência por ledger_file para impedir dois jobs mutáveis no mesmo recurso.

Arquivos novos
- ubet_service/settings.py
- ubet_service/schemas.py
- ubet_service/commands.py
- ubet_service/job_store.py
- ubet_service/job_runner.py
- ubet_service/api.py
- ubet_service/static/index.html
- run_service.py
- requirements_service.txt

Como instalar
1) python3 -m pip install -r requirements_service.txt
2) python3 run_service.py

Acesso
- UI: http://127.0.0.1:8010/
- Health: http://127.0.0.1:8010/health
- Jobs: http://127.0.0.1:8010/jobs

Endpoints principais
- POST /jobs/analysis
- POST /jobs/closing-odds
- POST /jobs/results-collection
- POST /jobs/settlement
- POST /jobs/daily-run
- GET  /jobs
- GET  /jobs/{job_id}
- GET  /jobs/{job_id}/logs
- POST /jobs/{job_id}/cancel

Exemplo: daily run
curl -X POST http://127.0.0.1:8010/jobs/daily-run \
  -H "Content-Type: application/json" \
  -d '{
    "date": "2026-04-23",
    "ledger_file": "data/history/bets_ledger.csv",
    "results_file": "data/results/results_auto.csv"
  }'

Exemplo: results only
curl -X POST http://127.0.0.1:8010/jobs/results-collection \
  -H "Content-Type: application/json" \
  -d '{
    "ledger_file": "data/history/bets_ledger.csv",
    "output_file": "data/results/results_auto.csv",
    "source": "auto",
    "debug": true
  }'
